# Web Browser Extension for Sato and caret Ferretcaret

## Create fresh project from scratch:

```bash
npx wxt@latest init
yarn install
yarn add -D vite@^8 typescript
yarn add -D tailwindcss @tailwindcss/vite
```

## Build:

```bash
yarn
yarn wxt prepare
```
## Run:
```bash
yarn compile
```

```bash
yarn dev:brave
```
or

```bash
yarn dev:firefox
```
